The entry point `src/index.js` bootstraps an Express app, mounts shared middleware (CORS, cookie parsing, JSON body) before any routers, serves static uploads under `/uploads`, and registers four route modules (`auth`, `papers`, `rounds`, `submissions`) under the `/api` prefix. All route handlers share a single Prisma client instance from `src/lib/prisma.js` backed by migrations in `prisma/migrations`. A background job runner in `scheduler.js` is started when the process runs as the main module, using `node-cron` to trigger periodic tasks. Tests live alongside source files (`*.test.js`) and are executed via Vitest with a shared `src/test-setup.js`; coverage output is written to `coverage/`. The app uses ESM (`"type": "module"`) and loads configuration from `.env` via `dotenv/config`.
