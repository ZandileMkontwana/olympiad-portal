A standalone Docusaurus 3.10 classic-preset site rooted at `documents/`, with configuration in `docusaurus.config.js` and sidebar routing in `sidebars.js`. Content is split into three Docusaurus collections: `docs/` (MDX/Markdown guides such as getting-started, api-reference, database-schema, round-lifecycle, tech-stack), `blog/` (MDX posts with authors.yml/tags.yml), and `src/pages/` (custom React pages like the homepage). Static assets live under `static/img/`, custom CSS under `src/css/custom.css`, and reusable UI via `src/components/HomepageFeatures`. The build output goes to `build/`, while `.docusaurus/` holds generated client code and `.netlify/` contains Netlify deployment metadata. Mermaid diagrams are enabled via the `@docusaurus/theme-mermaid` plugin, and Prism syntax highlighting uses GitHub/Dracula themes from `prism-react-renderer`. The site is deployed to Netlify (`url: https://loquacious-fairy-d08618.netlify.app`) and exposes RSS/Atom feeds through the blog preset.
