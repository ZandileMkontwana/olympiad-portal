The repository is organized as a flat monorepo with three sibling applications — `backend/` (Express REST API), `frontend/` (Next.js App Router client), and `docs/` (Docusaurus site) — each independently built and deployed. Cross-child wiring happens at the boundary: the frontend consumes the backend via a shared API client against the same Prisma-backed schema, while the docs site references both for architecture and API reference. Pre-commit quality gates are centralized in `.lintstagedrc.js`, which routes staged files to per-app linters/formatters (ESLint + Prettier for backend, a custom script for frontend). The root `README.md` delegates all user-facing documentation to the hosted Docusaurus site.
