Built on Next.js 16 App Router under `src/app`, with route segments organised by role (`login`, `register`, `organiser`, `educator`, `rounds/[id]`). The root layout in `src/app/layout.js` injects Google Fonts (Fraunces, Inter, IBM_Plex_Mono) and wraps every page with `SiteHeader`. Client-side behaviour is isolated to `src/hooks` — `useAuthRedirect` guards public pages by redirecting authenticated users to their dashboard, while `useRequireRole` enforces role-based access per route. All HTTP calls are funneled through `src/lib/api.js`, which exposes typed helpers (`createRound`, `uploadPaper`, `login`, etc.) over a configurable `NEXT_PUBLIC_API_BASE_URL` and throws a uniform `ApiError` with status codes. Static assets live in `public/`. Testing uses Vitest with jsdom and V8 coverage, configured via `vitest.config.mjs` with an `@` alias pointing at `src/`.
