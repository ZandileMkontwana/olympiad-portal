##

# When to commit:
<br/>after each logically complete, working chunk — not time-based
<br/>

# How to write commits: 
<br/>Conventional Commits format (type(scope): description) 
<br/>

# When to branch: 
<br/>one branch per ticket/task, off main
<br/>

# How to name branches: 
<br/> feature/function
<br/>

# When to merge:
<br/>
when the feature works and passes CI, via Pull Request — not direct pushes
<br/>

# Requirements for merging: 
<br/>
at least 1 approval + CI passing
<br/>

# When to version: 
<br/>
at sprint boundaries(end)
<br/>

# How to version: 
<br/>
MAJOR.MINOR.PATCH via git tags, with a CHANGELOG.md
<br/>
